# Focus Ring for Mac and Windows

The desktop installers for [Focus Ring](https://focus-ring.tech), a calm Pomodoro timer that stays in sync with your phone.

Download from **[focus-ring.tech/download](https://focus-ring.tech/download/)**, or pick a version under [Releases](https://github.com/korashy2018/focus-ring-releases/releases).

- **Mac:** macOS 12 or later, Apple silicon and Intel. Signed and notarized by Apple.
- **Windows:** Windows 10 or 11, 64-bit.

This repository holds only the installers. The app's code isn't here.
